# Pusthakk landing page

Static, responsive landing page for Pusthakk, built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Deployment
The GitHub Actions workflow at `.github/workflows/pages.yml` deploys the repository root when code is pushed to `main`.

If Pages has not been enabled for this repository yet, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source. The workflow will then publish the site.

The landing page links into the Pusthakk app at https://pusthakk.bolt.host/.
